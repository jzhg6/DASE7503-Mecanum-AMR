# 实车验收与提交清单

所有以下实物项目初始均为“待实测”。每项填写日期、操作者、软件commit、配置版本、
测量结果及照片/视频路径。程序构建通过不是实车验收通过。

| 步骤 | 验证动作 | 通过条件/证据 |
|---|---|---|
| 1 尺寸与电源 | 测整车三轴最大尺寸，包括升降极限、雷达、线缆；拔外接电源运行 | ≤300×300×180mm、电池独立运行，照片带尺 |
| 2 四轮 | 轮子架空逐个测试正反转/编码器，标记轮滚一周 | GPIO轮序、滚子朝向、正负号、counts/rev正确 |
| 3 运动标定 | 实测直行/侧移各1m，左右旋转一圈，记录odom | 校准半径、轴距、轮距、PID；误差小于本组机构容错 |
| 4 停止 | 停止速度发布、拔USB、关Agent、非法速度、/safety/stop | 无残余PWM推进，≤500ms速度看门狗；重新连接不自动使能 |
| 5 升降 | 从空载到最大实际货架载荷、全行程及重心偏移 | 单MG996无机械卡死；1500ms按实测调整；货架全程离地 |
| 6 相机 | 拍老师给本组的START/A/B/C/D/END | 6张真实标注PNG，码内容与纸质标签一致；保存日志/终端截图 |
| 7 雷达定位 | 看/scan、TF、地图叠加；货架搬走后重看costmap | 位置稳定；地图不把可移动货架留成永久障碍；无遮挡盲区 |
| 8 取货 | 在每个扫描位重复到达10次，验证错误码与正确码 | 错误货架/错误后缀不举升；正确码后精确进入、举升、退出 |
| 9 单次搬运 | 空载到A，搬到卸货1；再逐个检查B/C/D | 装载的机器人与货架均不碰墙；所有脚在目的区内、搬运不拖地 |
| 10 完整比赛 | 真START启动，不注入QR/导航成功/舵机成功 | 180秒内自动重复；到时停车；录像可数实际目的区货架 |
| 11 异常 | 扫码失败、导航被挡、舵机不确认、到时仍载物 | 错误停止且不计成功，迟到回调不能重启；保持载物姿态 |
| 12 评分记录 | 180秒时拍目的区与裁判记录 | 实际分数=5×目的区件数−2×撞墙次数；代码序列计数仅辅助 |

建议每件预算约40秒，4件160秒、剩余20秒裕量，这是设计预算，不是测得性能。
日志中的 `delivery_sequences` 只有在退出卸货区后增加，比裁判计件更保守。
当180秒发生在刚放下但尚未退出时，裁判可能计分而软件尚未计数，以裁判为准。
