# Pinned reference material

`minibot/` contains selected unmodified MIT-licensed launch, SLAM and command-mux
examples from commit `349140cfcdfd9b79d6a6c96f9aa2ac924f9f5378`. Both upstream
license files are retained. These examples target Jazzy and differential drive;
they are excluded from the active Humble workspace and are not ready-to-run
mecanum launch files. Use them while developing remote-station launch and teleop
arbitration. Do not launch two base controllers on one robot.

The other two reference repositories have no clear top-level reuse license.
Their URLs and exact revisions are recorded in `../upstreams.repos`; their files
are not redistributed. The local review checkouts remain outside this repository
at `E:/AIHKU/Class/7503/tmp/sources/`.
